## 우선순위 1: 즉시 처리 (1주 이내)

### `error.py` 잔버그 청소 (5분 내)
- `error.py:144` 메시지에 백틱 오타 — `"arguments is x\`wrong."` → `"arguments is wrong."`
- `InvalidCharacter` 클래스 중복 정의 (`error.py:175-182`, `205-212`) — 뒤쪽 중복 삭제
- 단순 청소이므로 진단/논의 없이 바로 처리

### 운영 로그 정책 결정
- `script.py`에 `js.console.log` 활성 8건 + 주석 처리 2건 잔존 (`built_in_functions.py`에 1건 추가)
- *우클릭 삭제 디버깅 잔재가 아님* — 대부분 운영 마일스톤 로그(`'월드 초기화'`, `'캐릭터 초기화'`, `'월드데이터 다운로드/업로드'` 등)
- 결정 기준 정하기:
  - 챕터/맵 전환 추적이나 사용자 문제 재현에 필요한 로그는 명시적 prefix 붙여 *남김* (`[w-world]` 등)
  - 단순 도달 표식("여기까지 옴")은 *제거*
  - 주석 처리된 죽은 로그는 모두 *삭제*
- 일관 기준 적용 후 한 번에 PR

## 우선순위 2: 단기 개선 (1개월)

### 메모리/리소스 정리
- 캐릭터 삭제 시 말풍선(speech bubble) DOM 잔존 여부 점검 (`character.py:155-162` 부근)
- `say()`/`print()`의 `setTimeout` 콜백이 캐릭터 삭제 후에도 살아 있는지 확인 — 필요 시 캔슬 핸들 보관
- `mob.py`/`modules.py`에도 `setTimeout` 다수 존재 (`mob.py:155, 175, 251, 312, 335`, `modules.py:42-94`) — 동일 패턴 점검 대상

### 로딩 인디케이터
- 맵 로드/초기화 시 스피너 표시 (현재는 빈 화면)
- 스토리 채점 진행 중 상태 표시
- 사용자 액션 일시 차단(Race Condition 방지)과 함께 처리하면 두 작업이 한 번에 정리됨

### 오류 메시지 *해결 힌트* 한 줄 추가
- 학습자가 모달로 보는 메시지는 이미 한글(`coordinate.py:77-99` `error_message`) — 영문은 콘솔 `print()` 출력뿐이므로 *통일 작업의 학습자 체감 효과는 낮음*
- 대신 *해결 힌트* 한 줄 추가가 학습자에게 직접적
  - 예: `'CharacterIsNotExist': '캐릭터가 존재하지 않습니다.'` → `'캐릭터가 존재하지 않습니다. set_character()로 먼저 생성하세요.'`
- 콘솔 영문 메시지의 한글화는 후순위 (개발자 친화 작업)

### Undo (Redo는 보류)
- 아이템/몹/벽 *배치* 직후 Ctrl+Z로 직전 1회만이라도 되돌리기
- 우클릭 삭제까지 도입된 상황에서 "잘못 놓았을 때" 가장 흔한 사용자 요구
- Redo, 다단계 히스토리는 후순위

## 우선순위 3: 학습 경험 강화 (1~2개월)

### 진행률 표시
- 챕터/문제별 완료 여부를 로컬 스토리지에 저장
- 상단 또는 사이드바에 "n/m 완료" 표시
- 학습 동기 부여에 가장 직접적인 항목

### 점진적 힌트 시스템
- 문제별 3단계 힌트 (방향 제시 → 의사 코드 → 코드 일부)
- 힌트 사용 여부는 학습자에게만 보이게 (점수 차감 등은 없음)

### 키보드 단축키
- `?` 키로 단축키 도움말 모달
- ESC(이미 구현됨), Ctrl+Enter(코드 실행) 등 현재 동작 정리

### 마우스 이벤트 성능 (측정 후 조치)
- `show_tooltip`(`script.py:743`) 등 mousemove 핸들러는 *현재 끊김/렉이 관측되지 않은 상태*
- 실제 체감 문제 또는 프로파일 결과가 나오면 그때 throttle(50ms) + 좌표→인덱스 매핑 캐시 적용
- 선제 최적화하지 않음
