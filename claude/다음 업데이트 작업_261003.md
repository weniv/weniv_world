## 이번 업데이트 (브랜치 `update/pyodide-worker`)

### 실행 환경 교체
- PyScript 2022.12(classic, 지원 종료) + Pyodide 0.23 → **Pyodide 314.0.7(Python 3.14)을 Web Worker에서 직접 실행**
  - PyScript 신버전이 아니라 Pyodide를 직접 쓴 이유: 신버전 PyScript는 워커에서 DOM을 쓰려면
    Cross-Origin Isolation 헤더(COOP/COEP)가 필요한데 GitHub Pages는 헤더를 설정할 수 없음.
    새 구조는 워커가 DOM을 쓰지 않으므로 헤더가 필요 없음.
  - Pyodide 314부터는 모듈 워커(`type: 'module'`)에서만 동작함
- 파이썬은 즉시 끝까지 실행하고 "이벤트 목록 + 실행 후 월드 상태"를 돌려줌 → 화면은 재생기가 속도에 맞춰 재생
- 무한 반복: 동작 10,000개 초과 시 `TooManyActions`, 순수 무한 루프는 `중지` 버튼(워커 재시작)
- 월드 상태는 화면(JS)이 보관 → 중지해도 월드는 유지, 셀 변수만 초기화

### 해결한 버그 (260502 검토 + 전체 코드 리뷰)
- `print('a', 'b')`가 공백 없이 붙던 문제, `sep`/`end` 미지원 → 실제 파이썬 print 사용
- 월드 내보내기 후 캐릭터가 움직이지 않던 문제 (얕은 복사로 `character_obj`가 지워짐)
- 같은 아이템 위에 `put()` 시 개수가 늘지 않던 문제 (들여쓰기 오류)
- 메뉴 PDF 다운로드 시 현재 탭이 이동하던 문제 (analytics의 preventDefault)
- 아이템이 있는 칸에 몹 배치 시 "맵을 벗어납니다" 오류
- 맵 축소 시 `initX` NameError
- 스토리 몹 방향 무시, lion 체력 200/250 불일치
- `jump()` 위치 갱신 지연, `typeof_wall()`이 아래/오른쪽 끝에서 None을 돌려주던 문제
- `CharacterIsNotExist` 등 import 누락으로 NameError가 나던 문제, `front_is_clear()` 디버그 출력
- Jupyter `.ipynb` 불러오기 시 줄 배열 source가 쉼표로 합쳐지던 문제
- 큰 프로필 사진 저장 실패 (256px로 줄여 저장)
- 아이템 우클릭 삭제가 벽 레이어에 가로막히던 문제 (`.wall-container`가 맵 전체를 덮음)
- `error.py` 백틱 오타, `InvalidCharacter` 중복 정의, 운영 console.log 정리

### 스토리 제출·채점 개편 (2026-10-04)
- 제출하면 스토리 월드를 처음 상태로 되돌리고, 노트북 셀 전체를 **학습자 변수와 섞이지 않는 새 환경에서
  처음부터 다시 실행**한 결과로 채점 (`runner.run_all`)
  - 이전: 마지막으로 실행한 뒤의 월드 상태로 채점 → 정답 코드를 두 번 실행하면 오답, 이전에 틀린 출력도 섞임
- 결과 창에 항목별 ✓/✗ 표시 (오류 없이 실행 / print 출력 / say 내용 / 캐릭터 위치 / 가진 아이템 / 맵에 남은 아이템 / 요구 문법)
  - 정답 값은 보여 주지 않음
  - 오류가 나면 몇 번째 셀 몇 번째 줄인지 안내하고 해당 셀 아래에 오류 표시
- 채점 규칙(부분 일치, 정답이 한 줄이면 마지막 출력과 일치)은 이전과 같음
- 제출 실행의 print 출력은 터미널에 `── n편 제출 ──` 구분선과 함께 표시
