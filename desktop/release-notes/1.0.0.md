위니브월드 설치판 첫 판이에요. 웹(위니버시티 학습 도구 > 위니브월드)과 같은 스토리 22편을 인터넷 없이 풀 수 있어요.

- 파이썬 3.14(Pyodide 314.0.7)를 앱에 넣어, 설치한 뒤에는 인터넷 없이 코드를 실행하고 스토리를 제출·채점해요.
- 진행 기록(통과한 스토리, 작성 중인 코드)은 이 컴퓨터에 남아 앱을 껐다 켜도 이어져요. 웹과 기록이 이어지지는 않아요.
- 선생님용·학생용 교안 PDF를 앱 안에서 내려받을 수 있어요.
- 앱은 바깥으로 아무 요청도 보내지 않아요(사용 기록·자동 업데이트 없음). 메뉴의 바깥 링크는 기본 브라우저로 열려요.

- Windows 설치판: `weniv-world-1.0.0-windows-x64-setup.exe`
- Windows 포터블: `weniv-world-1.0.0-windows-x64-portable.exe` (설치 없이 실행)
