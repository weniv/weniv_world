위니브월드 설치판 1.0.1이에요. Windows와 Mac 모두 정식 서명한 판이에요.

- Mac 앱을 Apple Developer ID로 서명하고 Apple 공증을 받았어요. 이제 처음 열 때 "확인되지 않은 개발자" 경고 없이 바로 열려요.
- Windows 설치 파일과 포터블은 WENIV Corp. 인증서로 서명돼 있어요.
- 노트북처럼 화면 높이가 낮을 때 아래 터미널이 잘리던 문제를 고쳤어요. 지도가 화면에 맞춰 줄어들어요.
- 화면 코드를 정리했어요(스토리·채점·진행 기록은 1.0.0과 같고, 1.0.0에서 남긴 기록도 그대로 이어져요).

내려받는 파일

- Windows 설치판: `weniv-world-1.0.1-windows-x64-setup.exe`
- Windows 포터블: `weniv-world-1.0.1-windows-x64-portable.exe` (설치 없이 실행)
- Mac: `weniv-world-1.0.1-mac-arm64.dmg`(Apple 실리콘), `weniv-world-1.0.1-mac-x64.dmg`(인텔)

앱은 바깥으로 아무 요청도 보내지 않아요(사용 기록·자동 업데이트 없음).
